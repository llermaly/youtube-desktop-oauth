Privacy notice

Updated October 4, 2026

This notice describes the personal desktop YouTube scripts for Gracias por Hoy and EmotionalResponses, using the Articles Admin and Doctor K YouTube Automation OAuth identities. It covers these YouTube workflows; it does not describe unrelated software that might use the same Google Cloud project.

Google data and permissions

The scripts request YouTube upload permission, permission to manage YouTube content and comments, and read-only YouTube Analytics access. They use these permissions to upload or schedule the owner's videos, manage channel content and comments, check the selected channel, and retrieve channel analytics.

Credentials and storage

Google handles account sign-in. The OAuth scripts save access and refresh tokens in local authorization files on the owner's computer. Those tokens are sent to Google when required to refresh authorization or make authorized API requests. Credentials are not included in this public information website.

The desktop workflows also store local channel metadata, publication records, and analytics needed for their operation. Video visibility is determined by the owner's publishing settings; published videos and comments are visible to their intended YouTube audience.

Scope of this website

This static information website has no sign-in form or application database. Its hosting provider may process standard website request information. Other tools used to produce video or audio have their own data practices and are outside this notice's description of the desktop OAuth scripts.

Remove authorization

The owner can revoke the app's access in Google Account connections and remove local authorization files when access is no longer needed. Revoking access prevents the stored tokens from continuing to authorize requests.
