Articles Admin

This page describes the personal desktop YouTube automation for Gracias por Hoy using the Articles Admin Google OAuth app identity.

The scripts run on the channel owner's computer. They request permission to upload videos, manage YouTube content and comments, and read YouTube Analytics. Google authorization is bound to the channel selected during sign-in.

This is a personal automation workflow. There is no public registration or hosted user application.
